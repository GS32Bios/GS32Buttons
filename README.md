# GS32Buttons
GS32Buttons - предназначена для удобного управления одиночными кнопками и группами кнопок. Поддерживает отслеживание одиночных и двойных кликов, удержаний, фиксацию нажатия при старте системы, а также регистрацию длительности состояний с использованием колбэков и лямбда-выражений C++.
